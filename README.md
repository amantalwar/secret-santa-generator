# 🎅 Secret Santa Generator

## 👉 [Play now at AmanTalwar.com/secret-santa](https://amantalwar.com/secret-santa/)

A free, rainbow-coloured Secret Santa generator. No sign-up, no ads, no data stored.

## How to play

1. The organiser sets the game name, budget, currency, optional date and message, and the number of players (3 to 20).
2. Add every player's name.
3. Optionally mark pairs who can't draw each other, such as couples.
4. Press **Draw names**. The organiser gets one private link per player to copy, WhatsApp or email.
5. Each player opens their link, taps the gift and sees who they're buying for.

Players can be in different countries and on different networks. They don't need to be online at the same time.

## Privacy

There is no account, server or database. Each player's match is stored inside their own link, so nothing is sent to or stored on a server.
